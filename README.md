# РемУчёт

Учебное веб-приложение для учёта запасных частей ремонтного подразделения.<br>
Ссылка на проект: [http://h198131.srv11.test-hf.su](http://h198131.srv11.test-hf.su)

## Установка и запуск

1. Импортировать базу MySQL: выполнить файл `server/database/schema.sql`.
2. Скопировать `.env.example` в `.env`, изменить настройки.
3. Установить backend-зависимости: `cd server` и `composer install`.
4. Запустить API: `php -S localhost:8000 -t public`.
5. Установить frontend-зависимости: `cd client` и `npm install`.
6. Запустить клиент: `npm run dev`.
7. Открыть приложение по адресу `http://localhost:5173`.

## Деплой проекта

Из корня проекта выполнить команду:

```bash
npm run deploy
```
Команда создаст папку `deploy`, которая загружается на сервер.
